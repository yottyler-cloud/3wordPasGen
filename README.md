# 3wordPasGen
パスワードジェネレーター

3つのキーワードから、毎回同じパスワードを生成する iPad 向けアプリです。
同じキーワードを入力すれば同じパスワードが再現されるため、パスワード自体を保存しておく必要がありません。

## 特徴
- **完全オフライン**: 通信は一切行いません。キーワードもパスワードも端末の外に出ません。
- **再現性**: キーワード3つ → SHA-512 → 乱数シード、という流れで決定的に生成します。
- **2種類同時に生成**: 記号あり / 記号なし（Python 版は12文字）
- **文字種を必ず含む**: 大文字・小文字・数字を必ず2文字ずつ（記号ありは記号も2文字以上）含みます。
- **見間違えやすい文字を除外**: `l` `1` `O` `0` は使いません。
- **色分け表示**: 数字は青、小文字は赤、それ以外は黒。
- **全角→半角を自動変換**: 全角で入力しても半角と同じ結果になります（NFKC正規化）。
- ワンタップでクリップボードにコピー、リセットボタンで入力と結果を消去。
- ブラウザ版のみ: パスワードは●で伏せ字表示（目のマークで表示切替）、
  文字数を 8 / 12（初期値・Python 版と同じ）/ 16 / 20 から選択、キーワード一括コピー（1行に1つ）。

## 構成
| パス | 内容 |
|---|---|
| `3wordPasGen.py` | Python 版（Pythonista 3 用） |
| `web/3wordPasGen.html` | ブラウザ版（HTML 1枚。Safari / Chrome 用） |
| `web/3wordPasGen2.html` | **新方式**のブラウザ版（下の「新方式」参照） |
| `3wordPasGen2.py` | **新方式**の Python 版（Pythonista 3 用） |
| `ios/3wordPasGen.swiftpm/` | Swift 版（**旧方式のまま・未更新**。Swift Playgrounds ではキーボードが出ないため保留中） |

ブラウザ版は Python 版と**同じキーワードから同じパスワード**を生成します。
Python の `random`（Mersenne Twister）の `seed` / `choices` / `sample` / `shuffle` と
`hashlib.sha512` を、同じ動作になるよう JavaScript で移植しています。

※ Swift 版は旧方式（文字種を保証しない版）の生成ロジックのままです。現在の Python 版とは結果が異なります。

## 新方式（3wordPasGen2）
現行方式は**一切変えず**、別ページ・別ファイルとして追加した方式です。同じキーワードでも現行とは違うパスワードになります。

- 公開ページ: `https://yottyler-cloud.github.io/3wordPasGen/web/3wordPasGen2.html`
- 材料:
  1. **暗証番号**（必須・4文字以上・数字以外も可）… 全サイト共通の「秘密の芯」。画面では伏せ字（目のマークで表示）。
  2. **キーワード × 3**（現行どおり）
  3. **サイト名**（必須）… サイトごとに別のパスワードになり、使い回しを防ぐ。
- サイト名の表記そろえ（入力中に「使う表記」を表示）:
  全角→半角、小文字化、空白をすべて除去、`https://` などを除去、最初の `/` `?` `#` 以降を除去、
  末尾のポート番号（`:8080`）・先頭の `www.`・末尾の `.` を除去。
  例: `https://www.Amazon.co.jp/gp/cart` → `amazon.co.jp`。
  サブドメインは残る（`accounts.google.com` と `google.com` は別扱い）ので、毎回同じ書き方で入れること。
- しくみ: 暗証番号・キーワード3つ・サイト名を NUL 文字で区切って連結 →
  **PBKDF2-HMAC-SHA512**（ソルト `"3wordPasGen2"` + NUL + サイト名、**210,000回**、64バイト）→ 16進 → `random.seed()`。
  以降の文字の選び方は現行と同じ（大文字・小文字・数字を2文字ずつ、記号ありは記号も2文字、除外文字 `l` `1` `O` `0`）。
  区切りを入れたので、「ab / c」と「a / bc」は別のパスワードになる。
- PBKDF2 でわざと計算を重くしている。総当たりの速さ（この環境の Python・1コア）は
  現行方式の毎秒約5万回 → 新方式は**毎秒約10回**。利用者側は「生成」1回あたり一瞬〜1秒程度。
  - ブラウザ版は、使えればブラウザ内蔵の Web Crypto（速い）、使えなければ自前の JavaScript で計算する（結果は同じ）。
  - くり返し回数（210,000）を変えるとパスワードが変わるので、変えないこと。
- 起動時の照合は、1,000回版の値6件と、本番の 210,000回の値1件で行う（終わるまで「生成」は「確認中…」）。
- 文字数: 12 / 16（初期値）/ 20
- 「キーワード・サイト名をコピー」は、キーワード3つとサイト名（そろえた表記）を1行に1つずつコピーする。**暗証番号は含めない。**
- 入力を変えると、表示中のパスワードは消える（別サイト用の取り違え防止）。
- 起動時に `3wordPasGen2.py` で生成した値と照合し、一致しなければ「生成」を無効にする。
  照合用の値は PC の Python で `python3 3wordPasGen2.py` を実行すると表示される（Pythonista では画面が開く）。
- **暗証番号を忘れると、新方式のパスワードは全部作れなくなります。** 忘れない工夫を（本人だけが分かる形で）。
- 弱いキーワードの警告は、まだ入れていない（保留）。

## ブラウザ版について
- HTML ファイル1枚だけで動きます。外部のファイルやライブラリは読み込みません。
- ページ内の CSP（Content-Security-Policy）で、**外部への通信をすべて禁止**しています。
- SHA-512 も自前で実装しているので、ネットに置かず、ファイルを開くだけでも動きます。
- 起動時に Python 版で生成した値と照合し、一致しない場合は警告を出して「生成」を無効にします。
- Service Worker（`web/sw.js`）で、初回に開いたときにページを端末に保存します。以後は保存した物だけを使うので、機内モードでも動きます。
  公開中のファイルが後から書き換えられても、保存済みのページは変わりません。
- アプリを更新したら `web/sw.js` の `CACHE_VERSION` を上げてください（上げないと端末側が更新されません）。
- `<script>` や `<style>` を書き換えたら、`python3 web/update_csp.py` を実行して CSP のハッシュを更新してください（しないとページが動かなくなります）。

## 使い方（ブラウザ版 / iPad）
1. Safari で `https://yottyler-cloud.github.io/3wordPasGen/web/3wordPasGen.html` を開きます。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから**一度オンラインで**開きます（ここで端末に保存されます）。
4. 以後は機内モードでも使えます。

## 使い方（Swift 版 / iPad）
1. `ios/3wordPasGen.swiftpm` フォルダを iPad の「ファイル」に置きます。
2. Swift Playgrounds で開いて実行します（Mac の場合は Xcode でも開けます）。
3. キーワードを3つ入力して「生成」をタップします。
4. 「記号ありコピー」または「記号なしコピー」でクリップボードにコピーします。

キーボードの自動大文字化・自動修正はオフにしてあります（入力が勝手に変わると別のパスワードになるため）。

## 使い方（Python 版 / Pythonista）
1. `3wordPasGen.py` を Pythonista にコピーします。
2. 実行するとシートが開きます。
3. キーワードを3つ入力して「生成」をタップします。
4. 「記号ありコピ」または「記号なしコピ」でクリップボードにコピーします。

## 注意
- 生成ロジック（文字セット、記号、文字数、ハッシュ方式、キーワードの結合方法）を変えると、
  **これまでと同じキーワードでも違うパスワードになります。** 変更するときは慎重に。
- コピーしたパスワードはクリップボードに残ります。使い終わったら別の文字をコピーするなどして消してください。
