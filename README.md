# 3wordPasGen
パスワードジェネレーター

3つのキーワードから、毎回同じパスワードを生成する iPad 向けアプリです。
同じキーワードを入力すれば同じパスワードが再現されるため、パスワード自体を保存しておく必要がありません。

## 特徴
- **完全オフライン**: 通信は一切行いません。キーワードもパスワードも端末の外に出ません。
- **再現性**: キーワード3つ → SHA-512 → 乱数シード、という流れで決定的に生成します。
- **2種類同時に生成**: 記号あり / 記号なし（12文字）
- **見間違えやすい文字を除外**: `l` `1` `O` `0` は使いません。
- **全角→半角を自動変換**: 全角で入力しても半角と同じ結果になります（NFKC正規化）。
- ワンタップでクリップボードにコピー、リセットボタンで入力と結果を消去。
- ブラウザ版のみ: パスワードは●で伏せ字表示（目のマークで表示切替、数字は赤）、
  文字数を 12（標準）/ 16 / 20 から選択、キーワード一括コピー（1行に1つ）。

## 構成
| パス | 内容 |
|---|---|
| `3wordPasGen.py` | Python 版（Pythonista 3 用） |
| `web/3wordPasGen.html` | ブラウザ版（HTML 1枚。Safari / Chrome 用） |
| `ios/3wordPasGen.swiftpm/` | Swift 版（SwiftUI。Swift Playgrounds / Xcode 用） |

Swift 版は Python 版と**同じキーワードから同じパスワード**を生成します。
Python の `random`（Mersenne Twister）の `seed` / `choices` / `sample` / `shuffle` を
`PythonRandom.swift` で同じ動作になるよう移植しています。
起動時に Python 版で生成した値と照合し、一致しない場合は画面に警告を表示します。

## ブラウザ版について
- HTML ファイル1枚だけで動きます。外部のファイルやライブラリは読み込みません。
- ページ内の CSP（Content-Security-Policy）で、**外部への通信をすべて禁止**しています。
- SHA-512 も自前で実装しているので、ネットに置かず、ファイルを開くだけでも動きます。
- 起動時に Python 版で生成した値と照合し、一致しない場合は警告を出して「生成」を無効にします。
- Service Worker（`web/sw.js`）で、初回に開いたときにページを端末に保存します。以後は保存した物だけを使うので、機内モードでも動きます。
  公開中のファイルが後から書き換えられても、保存済みのページは変わりません。
- アプリを更新したら `web/sw.js` の `CACHE_VERSION` を上げてください（上げないと端末側が更新されません）。
- `<script>` や `<style>` を書き換えたら、`python3 web/update_csp.py` を実行して CSP のハッシュを更新してください（しないとページが動かなくなります）。

## 使い方（ブラウザ版 / iPad）
1. Safari で `https://yottyler-cloud.github.io/3wordPasGen/web/3wordPasGen.html` を開きます。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから**一度オンラインで**開きます（ここで端末に保存されます）。
4. 以後は機内モードでも使えます。

## 使い方（Swift 版 / iPad）
1. `ios/3wordPasGen.swiftpm` フォルダを iPad の「ファイル」に置きます。
2. Swift Playgrounds で開いて実行します（Mac の場合は Xcode でも開けます）。
3. キーワードを3つ入力して「生成」をタップします。
4. 「記号ありコピー」または「記号なしコピー」でクリップボードにコピーします。

キーボードの自動大文字化・自動修正はオフにしてあります（入力が勝手に変わると別のパスワードになるため）。

## 使い方（Python 版 / Pythonista）
1. `3wordPasGen.py` を Pythonista にコピーします。
2. 実行するとシートが開きます。
3. 以降は Swift 版と同じです。

## 注意
- 生成ロジック（文字セット、記号、文字数、ハッシュ方式、キーワードの結合方法）を変えると、
  **これまでと同じキーワードでも違うパスワードになります。** 変更するときは慎重に。
- コピーしたパスワードはクリップボードに残ります。使い終わったら別の文字をコピーするなどして消してください。
